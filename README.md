Проект реализует и сравнивает три классических алгоритма для решения задачи коммивояжёра (TSP):
*   **Метод ветвей и границ** (Точный алгоритм)
*   **Поиск с запретами** (Tabu Search, метаэвристика)
*   **Жадный алгоритм** (Эвристика "ближайший сосед")

В папке report находятся файлы презентации проекта и отчет по проекту с описанием самого алгоритма и его реализации.
